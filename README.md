One emoji that stands for my AI agent: 🦉 the owl — wide awake at night, watching everything, reading, writing, running code, checking its work and submitting while its person sleeps.

## Run it

```sh
python3 main.py
```

That writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and re-validates it against the kit's gate (1–16 characters, valid UTF-8, not only white space).
